# AnyWhere

AnyWhere 是一款面向 Android 开发调试、功能测试与个人研究的位置环境模拟工具。

## 功能概述

- 地图选点与坐标/IP定位
- 静止、移动位置模拟
- 在 LSPosed 框架中启用，以获得完整功能
- 更多高级功能自行探索...

## 安装与使用

1. 下载适合设备架构的 APK；
2. 在系统“开发者选项”中，将 AnyWhere 设为模拟位置信息应用；
3. 在 LSPosed 中启用本模块、勾选作用域；
5. 启动应用并授予位置权限；
6. 在地图中选择位置并开始模拟。
